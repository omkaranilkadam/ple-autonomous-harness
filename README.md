# PLE-2026: Physical-Engineering's Last Exam — Agent Harness

A verification-first agent harness for the Google Agent Harness competition on Physical-Engineering's Last Exam (PLE).

## Architecture

```
[Task Input] → [Parser] → [Context Manager] → [Solver Loop]
                                ↑                    ↓
                          [Constraints]     [Tool Layer + S1-S12 Detectors]
                                ↑                    ↓
                          [Re-injection]    [Artifact Generator]
                                                     ↓
                                              [Self-Checks]
                                                     ↓
                                              [Done Frame]
```

## Quick Start

```bash
# Install dependencies
uv sync

# Run kit checks
uv run python -m kit check
uv run python -m kit artifacts

# Run dev evaluation
uv run python eval/run.py

# Run tests
uv run python tests/test_harness.py

# Start server
PORT=8080 uv run python serve.py
```

## Silent Failure Detectors (S1-S12)

| # | Class | Description |
|---|-------|-------------|
| S1 | Unit drift | mm vs m, kN vs N — dimensional analysis |
| S2 | Callout misread | Dual-parser agreement for rebar/dimensions |
| S3 | Wrong code clause | Edition-pinned clause lookup |
| S4 | IFC semantic error | Roundtrip write→read→compare |
| S5 | Clash float error | Tolerance band + explicit UNKNOWN |
| S6 | Swallowed tool error | Mandatory ok/value/error return |
| S7 | Context truncation | Constraint hash re-injection |
| S8 | Premature done | 100% deliverable checklist |
| S9 | Judge gaming | Non-emptiness + minimum content |
| S10 | Nondeterminism | 3× rerun variance check |
| S11 | Numeric precision | Alternate formula cross-check |
| S12 | Cross-artifact | Consistency graph verification |
